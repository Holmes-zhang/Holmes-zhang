# 一些日常折腾

这里放着我上课时会用的模板、想让电脑更顺手时做的小工具，以及偶尔用来~~搞抽象~~放空的小游戏。

### [家教课件模板](https://github.com/Holmes-zhang/tutoring-courseware)

家教时反复要用到公式、例题解析和板书，便把这些放进了一个离线 HTML 文件。复制一份、修改课程内容，就能继续上下一课。

支持公式排版、解析显隐、每页独立板书和会议模式。附 8 页示例与使用说明；板书只保留在当前页面会话中，需要留存时截图。

[在线预览](https://holmes-zhang.github.io/tutoring-courseware/) · [使用说明](https://github.com/Holmes-zhang/tutoring-courseware) · [复用模板](https://github.com/Holmes-zhang/tutoring-courseware/generate)

### [民办 mac](https://github.com/Holmes-zhang/minban-mac)

给 Windows 11 做一套圆润的悬浮任务栏：需要时出现，隐藏时让发出任务栏提醒的应用图标单独冒出来。基于 Windhawk 整理预设，并加入独立提醒、应用与恢复流程。

目前是 Windows 11 x64 的 Beta 版；多屏和不同系统补丁仍需验证。

[桌面效果](https://github.com/Holmes-zhang/minban-mac#桌面效果) · [下载与使用](https://github.com/Holmes-zhang/minban-mac/releases)

### [梗果忍者](https://github.com/Holmes-zhang/-)

把熟悉的梗做成竖屏切割小游戏。30 秒一局，按住划动、躲开炸弹，还有连斩、成就和可解锁的刀光。成绩与解锁进度保存在当前浏览器里。

用 HTML、CSS 和 JavaScript 实现，画面由 Canvas 绘制。

[开一局](https://holmes-zhang.github.io/-/)
